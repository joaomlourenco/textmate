# TextMate Development Guide

This project is the open-source repository for **TextMate**, a professional text editor for macOS. It is a large, modular codebase written in **Objective-C++**, combining high-performance C++ logic with native Cocoa GUI components.

## Project Overview

- **Purpose:** Professional text editor for macOS.
- **Architecture:** Highly modular, split into `Frameworks/` (core logic) and `Applications/` (UI and CLI tools).
- **Core Technologies:**
  - **Languages:** Objective-C++, C++, Objective-C.
  - **Logic Engines:** `buffer` (storage), `editor` (manipulation), `theme` (styling), `layout` (rendering).
  - **Third-party:** Boost, Cap'n Proto (serialization), Onigmo (regex), MultiMarkdown, Google SparseHash.

## Building and Running

### Prerequisites
Install dependencies via Homebrew:
```bash
brew install boost capnp google-sparsehash multimarkdown ninja ragel
```

### Build Commands
The project uses a custom build tool called `rave` that generates Ninja build files.
- **Configure:** `./configure` (This bootstraps `rave` and generates `build.ninja`).
- **Build TextMate:** `ninja TextMate`
- **Run TextMate:** `ninja TextMate/run`
- **Build CLI Tool:** `ninja mate`

### Testing
Tests are located in `tests/` directories within each Framework (e.g., `Frameworks/buffer/tests/`).
- **Run all tests:** `ninja tests`
- **Run specific test:** `ninja Frameworks/buffer/tests/run` (or similar targets generated by Ninja).

## Development Conventions

- **Multi-Cursor Support:** Logic for multiple cursors is primarily handled in `OakTextView.mm` via `document_view_t`. Bundle commands can opt-in to multi-cursor batching by setting `multiCursorSupport = true;` in their plist.
- **Coding Style:** Adhere strictly to existing patterns. Use `oak::` and `ng::` namespaces where appropriate.
- **Commits:**
  - Summary line < 70 characters.
  - Followed by a blank line and detailed reasoning/analysis.
  - Use `fixup!` or `amend` for local bug fixes before pushing.
- **Architecture:** 
  - Low-level data structures (e.g., `basic_tree_t`) are in pure C++.
  - GUI interactions are in Objective-C++ classes (prefixed with `Oak` or `OTV`).
- **Licensing:** The project is GPL-3.0-or-later. Contributors are encouraged to release patches as public domain to allow for non-free derivatives by the original creator.

## Key Directories

- `Applications/TextMate`: The main macOS application.
- `Applications/mate`: The command-line companion.
- `Frameworks/OakTextView`: The core text rendering and interaction engine.
- `Frameworks/buffer`: Low-level text storage (AA-trees).
- `Frameworks/editor`: High-level text manipulation logic.
- `vendor/`: Bundled third-party dependencies.
